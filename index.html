How it works

Each KPI's month-to-month change is correlated with the outcome's change at lags of 0 to 2 months, which removes shared trends. KPIs with |r| of 0.5 or more are drivers, and the strongest are combined in a regression to split last month's change into contributions. In production, an LLM would write the briefing and answer questions from these computed numbers only, citing the evidence for every claim. Correlation is not proof of cause, so major decisions should be confirmed with experiments.
